# Profe Anto

Página principal de https://u-anto-proyectos.github.io/

Un universo matemático: las estrellas forman constelaciones con curvas (parábola, espiral, rosa, lemniscata, campana de Gauss…). Al tocar el cielo nace una constelación; al mover el dedo o el mouse, las estrellas cercanas se conectan.

Un solo archivo (`index.html`), sin dependencias, sin zoom y con `prefers-reduced-motion`.
